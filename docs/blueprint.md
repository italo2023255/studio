# **App Name**: LexQuiz AI

## Core Features:

- Question Generation: Generates multiple-choice questions based on a provided legal text, ensuring each question has 4 answer choices and includes the correct answer.
- Answer Generation: Automatically provides a correct answer key (gabarito) and detailed explanations for each question, referencing the original legal text. The explanations should be able to reason and provide appropriate legal insight depending on the type of law that it is.
- Internet Search: Uses a search tool to find relevant information about the legal answers and related content on the internet.  It adds links and references to jurisprudence sites or legal blogs that are deemed useful.
- Mnemonic Generation: Generates mnemonic devices, tricks, and memory aids related to the questions. The LLM should act as a tool and selectively weave in the mnemonic aids, as well as selectively decide when one mnemonic is more applicable or useful than another depending on the circumstances.
- UI Display: Displays questions, answer choices, and explanations in a clean and professional design optimized for readability. Use intuitive navigation.

## Style Guidelines:

- Primary colors: Blue and White for a professional and clean look.
- Secondary color: Gray to complement the primary colors and provide visual balance.
- Accent: Use a vibrant Teal (#008080) for interactive elements such as buttons and links to draw attention.
- Clear and professional sans-serif fonts for easy readability.
- Use simple, recognizable icons for navigation and key features.
- Responsive layout that adapts to different screen sizes (mobile, tablet, desktop).
